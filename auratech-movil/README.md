# AuraTech Mobile

Aplicación Flutter para clientes y técnicos de AuraTech.

**Empieza por [REQUISITOS_Y_EJECUCION.md](REQUISITOS_Y_EJECUCION.md).** Allí están las versiones comprobadas, la configuración de Android y Java, el backend necesario y los comandos para ejecutar la app.

El frontend no incluye el backend ni usuarios de prueba. La pantalla de acceso se abre sin servidor, pero el registro y el inicio de sesión requieren la API de AuraTech.
